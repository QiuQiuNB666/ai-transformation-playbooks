案例报告与前面的行业打法体例不同：它不覆盖全行业，只回答这一家店该怎么干，并且凡结论依赖尚未取得的信息（收银主体、证照持证方、商场扣点基数等），一律写成 if-then 两条分支。其中的「可能在亏损」等表述是条件推演，不是对该店实际经营数据的断言。

**三份的定位要分清。** 调研报告是诊断，营销方案是我方能交付且能负责的部分（线上门面、对客物料、内容素材、钩子与复购装置），执行计划是店主自己的经营管理动作。营销服务方不进客户的账本与后厨：成本测算、供应端、食安、排班、证照这些只能作为诊断依据引用一句，不能变成我方的动作或排期。营销方案里每一项的验收标准都是交付物本身的完成状态，不是店铺营收与客流。

## 行业打法系列的统一体例

两份行业打法属于同一系列，章节结构一致，便于横向对照：

```
0. 先看这三句
1. 值钱的到底是哪几段
2. 全链路场景地图
3. 三套打法（按主体分）
4. 统一劝退清单
5. 合规红线
6. 工具表
7. 怎么判断有没有用
8. 附录：可直接复制的提示词
9. 待核实清单
10. 参考来源
```

两条贯穿全系列的纪律：

- 每个场景标注 **已验证可做 / 值得试 / 噱头劝退**，不做没有依据的推荐。
- 厂商与平台自述的效果数据一律标注来源性质，不得当作 KPI 目标值。价格拿不到就写「需询价」，不编。

## 勘误

**BUD 与身份线共四条硬伤已改正**（2026-09-16）。BUD 配对比例是政府 25% 不是 50%；BUD 明文禁止聘用关联方，「深圳申报、香港实施」不成立；「虚拟地址不再被入境处接受」无一手来源；续签豁免收入证明仅限高才通中获指定公营机构支持的初创科企经营者、2027 年上半年生效。详见[待核实核查结果.md](待核实核查结果.md)，《诚一智企布局》顶部有勘误块。

**「出关 20 米」不可用于任何对客物料**（2026-09-15 发现，影响锦鹏记系列四份文档共约 48 处引用）。

该数字源自港媒开业报道「一出關口步行約20米直達」，但原文主语是粤港新天地这个商场，不是锦鹏记这个档口；且该表述系同一份开业新闻稿被多家媒体逐字转载，属单一稿源扩散，不构成交叉验证。同批信源中另有攻略写「過關後步行約3分鐘」，按常速约 200 米以上，与 20 米差一个量级。

对客一律改用无数字口径「羅湖口岸出關即到」。米数与转向须现场实测后，只回填到动线小图的角落，不进任何主标题。受影响文档顶部已各加一行提示，正文引用未逐处删改，以免引入新错误。

这条勘误是用文档自己立的规矩量自己得出的：不能核实就不能写。

## 使用前必读

**所有文档都带「待核实」标记，落地前必须自己确认。** 工具价格、平台产品名与免费范围、政策条款、行业数据都会变，标记项汇总在各文档的「待核实清单」一节，写明了去哪里核实。

几条已知的高优先级待核实项：

- 各 AI 工具的当日价格与功能开放状态，采购前以官网或后台实际显示为准。
- 平台侧产品名与免费范围，以商家后台实际入口为准。
- 法规条文编号，引用前回原文核对。
